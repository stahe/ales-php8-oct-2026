    22. Ejercicio práctico – Versión 11

    Todavía es común que los servicios web envíen su respuesta en forma de documento XML en lugar de un documento JSON:

    • el documento JSON es más pequeño, pero se necesitan instrucciones para entenderlo;
    • el documento XML es más extenso, pero se explica por sí mismo. Se entiende de inmediato.

    Modificamos la aplicación cliente/servidor de la versión 10 para que el servidor envíe ahora un documento XML como respuesta a sus clientes. Con ello, ponemos en práctica el capítulo anterior.

    <?php

declare(strict_types=1);

// espacio de nombres
namespace Application;

// funciones utilitarias para el formato XML: la clase no se puede instanciar ni derivar
final class XmlUtilities
{
    // constructor privado: la clase no puede instanciarse
    private function __construct()
    {
    }

    // devuelve el documento XML de un arreglo [$data]: el elemento raíz se llama [$root]
    // las claves del arreglo se convierten en nombres de elementos, los valores en su contenido
    public static function arrayToXml(array $data, string $root): string
    {
        // un documento XML vacío (nueva API DOM de PHP 8.4)
        $document = \Dom\XMLDocument::createEmpty();
        // el documento tendrá sangría
        $document->formatOutput = true;
        // el elemento raíz y sus descendientes
        $document->append(self::element($document, $root, $data));
        // el texto XML del documento
        return $document->saveXml();
    }

    // devuelve el elemento XML [<$name>$value</$name>]
    private static function element(\Dom\XMLDocument $document, string $name, mixed $value): \Dom\Element
    {
        $element = $document->createElement($name);
        if (is_array($value)) {
            // un arreglo: cada elemento del arreglo se convierte en un elemento hijo (llamada recursiva)
            foreach ($value as $key => $subValue) {
                // los elementos de una lista (claves 0, 1, 2...) se llaman [item]
                $element->append(self::element($document, is_int($key) ? "item" : $key, $subValue));
            }
        } else {
            // un valor simple se convierte en el texto del elemento (DOM codifica los caracteres <, >, &)
            $element->textContent = match (true) {
                is_bool($value) => $value ? "true" : "false",
                default => (string) $value,
            };
        }
        return $element;
    }
}

    Comentarios

    • línea 9: al igual que la clase [Utilities] de la versión 5, esta clase solo tiene métodos estáticos. Es [final] y su constructor es privado: no se puede derivar de ella ni instanciarla;
    • línea 18: el método estático [arrayToXml] devuelve el documento XML a partir del arreglo [$data] pasado como parámetro. El segundo parámetro es el nombre del elemento raíz del documento;
    • línea 21: usamos la nueva API DOM de PHP 8.4, presentada en el capítulo anterior. El método estático [createEmpty] crea un documento XML vacío. El script de PHP 7 usaba [SimpleXML], que también puede generar un documento, pero no tan bien: había que codificar uno mismo los caracteres especiales del texto con la función [htmlspecialchars];
    • línea 23: el documento resultante estará indentado, lo que lo hace más legible;
    • línea 25: el elemento raíz del documento, creado por el método [element], se agrega al documento;
    • línea 27: el método [saveXml] genera el texto XML del documento;
    • línea 31: el método privado [element] devuelve el elemento XML con el nombre [$name], que representa el valor [$value];
    • línea 33: el método [createElement] del documento crea el elemento;
    • Líneas 34–38: si el valor es un arreglo, cada uno de sus elementos se convierte en un elemento hijo, creado mediante una llamada recursiva al método [element]. Las claves del arreglo se convierten en los nombres de los elementos hijos. Las claves de una lista son los enteros 0, 1, 2..., que no pueden ser nombres de elementos XML: por eso estos elementos se llaman [item]. El script de PHP 7 los designaba como [i0], [i1], [i2]...;
    • líneas 40–45: de lo contrario, el valor se convierte en el texto del elemento, asignado a su propiedad [textContent]. Los caracteres [<], [>], y [&] del texto son codificados por DOM ([&lt;], [&gt;], [&amp;]). Los booleanos se escriben como [true] y [false]; los demás valores se convierten en cadenas. La expresión [match (true)] selecciona la primera rama cuya condición es verdadera.

// envío de la respuesta HTTP al cliente
// $result: el arreglo que se enviará, en forma del documento XML <response>...</response>
// $statusCode: el estado HTTP de la respuesta
// $headers: encabezados HTTP que se agregarán a la respuesta
// $logger: el registro de la aplicación (null si no se pudo crear)
// $redis: el cliente Redis (null si aún no se ha creado)
function sendResponse(
    array $result,
    int $statusCode,
    array $headers = [],
    ?Logger $logger = null,
    ?RedisClient $redis = null
): void {
    // la respuesta XML
    $response = new Response(XmlUtilities::arrayToXml($result, "response"), $statusCode, $headers);
    $response->headers->set("Content-Type", "application/xml; charset=utf-8");
    // envío
    $response->send();
    // registro en JSON, más conciso que XML
    $logger?->write(json_encode(
        ["response" => $result],
        JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_PRESERVE_ZERO_FRACTION
    ));
    // cierre de la conexión con el servidor Redis
    $redis?->disconnect();
}

            // hacemos la solicitud al servidor
            $response = $this->httpClient->request("GET", $this->urlServer, $options);
            // el estado, los encabezados y el documento XML de la respuesta, incluso en caso de error (parámetro false)
            $statusCode = $response->getStatusCode();
            $headers = $response->getHeaders(false);
            $content = $response->getContent(false);
        } catch (ExceptionInterface $ex) {
            // no se pudo contactar al servidor
            throw new TaxException("Error communicating with the server ({$ex->getMessage()})", 40, $ex);
        }
        // registros
        // print "$content\n";
        // el servidor envía el documento XML <response>...</response>
        // las opciones LIBXML_NOERROR y LIBXML_NOWARNING evitan las advertencias de PHP si el XML es inválido
        $xml = simplexml_load_string($content, options: LIBXML_NOERROR | LIBXML_NOWARNING);
        if ($xml === false || $xml->getName() !== "response") {
            throw new TaxException("Invalid server response [$content]", 41);
        }
        // ¿error?
        if ($statusCode !== 200) {
            // lanzamos una excepción cuyo mensaje es la respuesta del servidor, convertida a JSON (más conciso),
            // completada con su estado HTTP
            $serverResponse = json_decode(json_encode($xml, JSON_THROW_ON_ERROR), true, flags: JSON_THROW_ON_ERROR);
            $message = json_encode(
                ["HTTP status" => $statusCode] + $serverResponse,
                JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR
            );
            throw new TaxException($message, 42);
        }
        // recuperamos la cookie de sesión si aún no se conoce
        if ($this->sessionCookie === null) {
            foreach ($headers["set-cookie"] ?? [] as $cookie) {
                if (preg_match('/^PHPSESSID=(.+?);/', $cookie, $fields) === 1) {
                    $this->sessionCookie = "PHPSESSID=$fields[1]";
                }
            }
        }
        // devolvemos la respuesta: el arreglo [tax, surcharge, discount, reduction, rate]
        // en el documento XML, todos los valores son textos: los convertimos a su tipo
        return [
            "tax" => (int) $xml->tax,
            "surcharge" => (int) $xml->surcharge,
            "discount" => (int) $xml->discount,
            "reduction" => (int) $xml->reduction,
            "rate" => (float) $xml->rate,
        ];
    }
}

    Comentarios

    • línea 63: se lee la respuesta del servidor. Es un documento XML [<response>…</response>];
    • línea 72: la función [simplexml_load_string] analiza el documento XML recibido y devuelve un objeto [SimpleXMLElement] que representa su elemento raíz, o [false] si el documento no es un documento XML válido. De forma predeterminada, la biblioteca [libxml] que usa [SimpleXML] también informa los errores del documento como advertencias de PHP: las opciones [LIBXML_NOERROR] y [LIBXML_NOWARNING] las suprimen. Se pasan mediante el argumento con nombre [options], lo que evita tener que escribir el parámetro [class_name] que lo precede en la firma de la función;
    • línea 73: el método [getName] devuelve el nombre del elemento raíz, que debe ser [response];
    • Líneas 77–85: en caso de error, el mensaje de la excepción será la cadena JSON de la respuesta del servidor y no la cadena XML recibida, porque la cadena JSON es más concisa. Para obtener el arreglo asociativo de la respuesta XML, usamos un truco clásico: la función [json_encode] puede convertir un objeto [SimpleXMLElement] en JSON, y [json_decode] convierte luego este JSON en un arreglo. Así, el mensaje de la excepción tiene el mismo formato que en las versiones anteriores;
    • líneas 97–103: se devuelve el arreglo de resultados. Se accede a los elementos hijos del elemento [response] como propiedades del objeto [$xml] ([$xml->tax]). En un documento XML, todos los valores son texto: a diferencia de JSON, XML no distingue entre enteros, números reales y cadenas de caracteres. Por lo tanto, cada valor se convierte al tipo que espera la capa [business] mediante los operadores [(int)] y [(float)] . El cliente de PHP 7 devolvía los valores como cadenas.
