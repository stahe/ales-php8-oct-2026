    2. Configuración de un entorno de desarrollo

    Los scripts se escribieron y probaron en el siguiente entorno:

    • un entorno de servidor web [Apache] / SGBD [MySQL] / [PHP] 8.5 llamado [Laragon];
    • el editor [Visual Studio Code] y su extensión [PHP Intelephense];
    • el administrador de dependencias [Composer], que se incluye con [Laragon], y que instala las bibliotecas de PHP utilizadas por el curso.

    Otras herramientas (el servidor de correo [Mailpit], el SGBD [PostgreSQL] y el servidor [Redis]) solo son relevantes para ciertos capítulos: su instalación se describe en los capítulos correspondientes.

    2.1. Instalación de Laragon

    [Laragon] es un paquete para [Windows] que combina varios componentes de software:

    • un servidor web ([Apache]). Lo usaremos para escribir scripts web en PHP;
    • el SGBD [MySQL] (a este se le puede agregar [PostgreSQL] , véase el capítulo de la versión 6);
    • el lenguaje de scripts PHP, en varias versiones, entre ellas la versión 8.5;
    • un servidor [Redis] que implementa un caché para aplicaciones web;
    • la herramienta [Composer];
    • un terminal de línea de comandos en el que se pueden usar directamente todas estas herramientas.

    [Laragon] puede descargarse desde https://laragon.org/download/. Es gratuito con todas sus funciones; ocasionalmente aparece un aviso que invita a comprar una licencia para apoyar su desarrollo, lo cual es opcional. La instalación es sencilla: basta con aceptar la configuración predeterminada. [Laragon] se instala entonces en la carpeta [C:\laragon], a la que nos referiremos de aquí en adelante como <laragon>:

    1
2
3
4
5
6
    C:\laragon
├── bin\        the software: apache, mysql, php, redis, composer…
├── data\       the DBMS data
├── etc\        configuration files
├── tmp\
└── www\        the root of the Apache web server: http://localhost

    Al iniciar [Laragon] se muestra su ventana principal:

    • El botón [Démarrer tout] (Iniciar todo) inicia el servidor web [Apache], así como el SGBD [MySQL]. La ventana indica entonces, para cada uno de ellos, que está activo y en qué puerto escucha: 80 para [Apache], 3306 para [MySQL];
    • el botón [Web] muestra la página [http://localhost], que corresponde a la carpeta [<laragon>/www];
    • el botón [Base de données] (Base de datos) abre una herramienta de administración de bases de datos ([HeidiSQL], incluida con [Laragon]);
    • El botón [Terminal] abre un terminal de comandos en el que se pueden usar directamente [php], [composer], [mysql]…;
    • El botón [Racine] (Raíz) abre el explorador de archivos de [Windows] en la carpeta [<laragon>/www]. Allí es donde se deben colocar todas las aplicaciones web administradas por el servidor [Apache] de [Laragon];
    • Al hacer clic con el botón derecho en la ventana (o en el ícono de [Laragon] en la barra de tareas) se abre el menú de [Laragon], que da acceso a los parámetros de configuración de cada aplicación.

    2.1.1. Selección de PHP 8.5

    [Laragon] puede contener varias versiones de PHP. La versión que se usará se selecciona desde su menú, en la sección [PHP > Version]. Seleccione la versión 8.5 (la más reciente de la serie 8.5). Esta será utilizada tanto por el servidor [Apache] como por el comando [php] del terminal.

    Para que el comando [php] también pueda usarse en los terminales de [VS Code], la carpeta de PHP debe estar incluida en el PATH de [Windows]. [Laragon] se encarga de ello: menú [Tools > Path > Add Laragon to Path]. Luego abra un nuevo terminal (los terminales que ya estén abiertos no verán el cambio) y escriba:

    1
    > php -v

    El comando debería mostrar la versión de PHP, 8.5.x.

    2.1.2. Configuración de PHP para el curso

    PHP se configura mediante un archivo de texto llamado [php.ini], accesible desde el menú de [Laragon], en la sección [PHP > php.ini]. Durante el aprendizaje, PHP debe informar todos los errores, advertencias y obsolescencias. Verifique que el archivo contenga las siguientes líneas (o modifíquelas):

    1
2
3
4
5
6
    error_reporting = E_ALL
display_errors = On
display_startup_errors = On
log_errors = On
error_log = C:/laragon/tmp/php_errors.log
date.timezone = Europe/Paris
    • [error_reporting = E_ALL]: PHP informa todo, incluidos los mensajes [Deprecated] que anuncian características obsoletas. Una configuración de producción suele usar [E_ALL & ~E_DEPRECATED], que los oculta: eso no es lo que queremos aquí;
    • [display_errors = On]: los mensajes se muestran en la salida del script (el terminal o la página web);
    • [log_errors = On]: los mensajes también se escriben en el registro de errores;
    • [error_log]: el archivo de registro. Sin esta línea, un script de consola escribe su registro en el propio terminal, y cada mensaje aparecería allí dos veces (una precedido por [PHP], otra sin él);
    • [date.timezone]: la zona horaria utilizada por las funciones de fecha.

    El curso también utiliza varias extensiones de PHP. Se habilitan en el menú de [Laragon], en la sección [PHP > Extensions], o en el archivo [php.ini] mediante líneas de la forma [extension=name]. Las extensiones utilizadas son: [curl], [mbstring], [openssl], [pdo_mysql], [pdo_pgsql], [fileinfo] y [zip] (esta última la usa [Composer] para descomprimir las bibliotecas que descarga). Después de modificar el archivo [php.ini], debe reiniciar [Apache] (el botón [Reload] en [Laragon]); en cambio, los scripts de consola vuelven a leer el archivo [php.ini] cada vez que se ejecutan.

    Puede verificar la configuración en un terminal con el comando [php --ini] (el archivo [php.ini] utilizado) y [php -m] (la lista de extensiones cargadas). El primer script del próximo capítulo, [phpinfo.php], muestra toda la configuración.

    2.2. Instalación de VS Code

    [Visual Studio Code] es un editor gratuito de Microsoft, disponible para descargar en https://code.visualstudio.com/. Aquí reemplaza al IDE [NetBeans] utilizado en el curso de PHP 7.

    Una vez instalado [VS Code] , agregue la compatibilidad con el lenguaje PHP: en el panel [Extensions] (Ctrl+Shift+X), busque e instale la extensión [PHP Intelephense]. Esta proporciona:

    • autocompletado de código: las funciones, clases, métodos y atributos de PHP se sugieren a medida que se escribe;
    • visualización de la documentación de una función o método al pasar el mouse sobre su nombre;
    • detección de errores mientras se escribe (variables no definidas, tipos incorrectos, métodos inexistentes, etc.), que se subrayan en el código y se listan en el panel [Problems];
    • navegación por el código: al presionar Ctrl+clic sobre el nombre de una clase o función se abre su definición, incluidas las de las bibliotecas de la carpeta [vendor].

    [Intelephense] debe conocer la versión de PHP utilizada para identificar sus novedades: en la configuración de [VS Code] (Ctrl+coma), busque “intelephense php version” e ingrese 8.5.

    A continuación, abra la carpeta del código del curso en [VS Code] (menú [File > Open Folder]). Se abre un terminal desde el menú [Terminal > New Terminal]: está ubicado en la carpeta abierta, y allí se escriben los comandos [php], [composer], [curl]… Para ejecutar un script de consola, navegue a su carpeta (comando [cd]) y escriba [php script-name.php].

    2.4. Instalación de bibliotecas con Composer

    Como la mayoría de los lenguajes de programación, PHP cuenta con un administrador de dependencias, [Composer], que descarga las bibliotecas que necesita un proyecto desde el repositorio [packagist.org].         "sort-packages": true

    • Línea 6: las bibliotecas necesarias para ejecutar los scripts. Cada una se identifica con un nombre de la forma [vendor/library] y una restricción de versión: [^8.0] significa “cualquier versión de 8.x a partir de 8.0”. Sus funciones se describen en los capítulos que las utilizan;
    • línea 7: el proyecto requiere PHP 8.5 o posterior;
    • línea 15: bibliotecas utilizadas únicamente para el desarrollo, en este caso el framework de pruebas [PHPUnit].

    Para instalar estas bibliotecas, abra un terminal en la carpeta [php8-oct-2026] (el terminal de [Laragon] o el terminal de [VS Code]) y escriba:

    1
    > composer install

    [Composer] crea entonces una carpeta llamada [vendor] que contiene las bibliotecas y sus dependencias, así como un archivo llamado [vendor/autoload.php]. Un script que desee usar estas bibliotecas solo necesita incluir este archivo, que carga automáticamente sus clases la primera vez que se utilizan. Los scripts de este curso lo hacen con una ruta relativa a su propia carpeta, por ejemplo:

    1
    require_once __DIR__ . '/../../vendor/autoload.php';

    La constante [__DIR__] hace referencia a la carpeta del script que la utiliza: por lo tanto, la ruta no depende de la carpeta desde la que se ejecuta el script ni de dónde se encuentre la carpeta [php8-oct-2026].

    Verifique la instalación mostrando la versión de [PHPUnit]:

    1
2
    > php vendor/bin/phpunit --version
PHPUnit 12.5.37 by Sebastian Bergmann and contributors.
