    En esta configuración:

    • líneas 2–6: las rutas de todos los archivos JSON de la aplicación. La base de datos utilizada es PostgreSQL;
    • líneas 7–20: las rutas de todos los archivos PHP de la aplicación, con el formato [key => path]. Son los archivos de la versión 5;
    • líneas 21–32: las dependencias para el cálculo del impuesto, en forma de una lista de claves del diccionario [dependencies];
    • líneas 33–40: las dependencias para transferir los datos del archivo JSON [taxadmindata.json] a la base de datos, con el mismo formato.

    Todas las rutas son relativas a la carpeta [version-07]. El curso de PHP 7 agregaba a este archivo una clave llamada [rootDirectory], que especificaba la ruta absoluta de la carpeta de la versión en la máquina del autor (["C:/Data/st-2019/dev/php7/poly/scripts-console/impots/version-07"]): había que modificarla en cada máquina nueva. Ahora los scripts calculan por sí mismos la ruta de esta carpeta a partir de la constante [__DIR__]. Por lo tanto, la carpeta [php8-oct-2026] puede colocarse en cualquier lugar.

// respeto estricto de los tipos declarados de los parámetros y resultados de las funciones
declare(strict_types=1);

// espacio de nombres
namespace Application;

// la carpeta raíz de la versión 7: las rutas del archivo de configuración son relativas a esta carpeta

// recuperamos la configuración

    print "The data of the tax administration have been transferred into the database described by [{$config["databaseFilename"]}]\n";
} catch (TaxException $ex) {
    // mostramos el error
    print "Error no. {$ex->getCode()}: {$ex->getMessage()}\n";

    Comentarios

    El código sigue siendo el mismo que en la versión 6. La única diferencia es el uso del archivo [config.json] en lugar de las constantes:

    • Línea 10: el directorio raíz de la versión 7, respecto del cual se miden las rutas del archivo de configuración. [__DIR__] es la carpeta [Main] del script; [__DIR__ . "/.."] es su carpeta padre, [version-07];
    • línea 12: la ruta del archivo de configuración;
    • línea 15: la función [file_get_contents] convierte el archivo [config.json] en una cadena. Luego, la función [json_decode] usa esta cadena para construir el arreglo asociativo [$config]. El segundo parámetro, [true], de la función [json_decode] especifica que se desea un arreglo asociativo en lugar de un objeto. Con la opción [JSON_THROW_ON_ERROR], un error de sintaxis en el archivo provoca una excepción [JsonException]. Aquí no intentamos manejar los errores de lectura del archivo de configuración: este archivo forma parte de la aplicación, y un error en este nivel es un error de programación que PHP informa por sí mismo. Los errores de datos (archivos de datos JSON, base de datos) siempre los informa una [TaxException];
    • líneas 18–20: se incluyen las dependencias requeridas por el script de transferencia:
      • [$config["dependencies4transfer"]] es la tabla de dependencias requeridas por el script de transferencia. Es una lista de claves;
      • las rutas de los archivos que se van a incluir se encuentran en el diccionario [$config["dependencies"]] y llevan como prefijo el directorio raíz. Por ejemplo, la clave [TaxException] hace referencia al archivo [version-07/../version-05/Entities/TaxException.php];
      • [require_once] (y no [require] como en el curso de PHP 7) garantiza que un archivo no se cargue dos veces, lo que provocaría el error fatal “Cannot redeclare class … (previously declared in …)”;
    • líneas 23–24: las rutas completas de los archivos de datos. El curso de PHP 7 las almacenaba en constantes creadas con la función [define]. Las variables son suficientes;
    • línea 31: se muestra el nombre del archivo que describe la base de datos utilizada. En una cadena entre comillas, el elemento de arreglo [$config["databaseFilename"]] debe ir entre llaves.

    <?php

// respeto estricto de los tipos declarados de los parámetros y resultados de las funciones
declare(strict_types=1);

// espacio de nombres de las pruebas
namespace Application\Tests;

// las clases probadas
use Application\DaoTaxWithTaxAdminDataInDatabase;
use Application\DaoTransferAdminDataFromJsonFile2Database;
use Application\TaxAdminData;
// las clases de PHPUnit
use PHPUnit\Framework\Attributes\DataProvider;
use PHPUnit\Framework\TestCase;

final class DaoTest extends TestCase
{
    // la carpeta raíz de la versión 7
    private const string ROOT_DIRECTORY = __DIR__ . "/..";
    // la configuración de la aplicación
    private static array $config;

    // se ejecuta una vez, antes de la primera prueba de la clase
    #[\Override]
    public static function setUpBeforeClass(): void
    {
        // recuperamos la configuración
        self::$config = json_decode(file_get_contents(self::ROOT_DIRECTORY . "/Data/config.json"), true, flags: JSON_THROW_ON_ERROR);
        // incluimos las dependencias del cálculo del impuesto y las de la transferencia de datos
        $dependencies = array_unique([...self::$config["dependencies4calculate"], ...self::$config["dependencies4transfer"]]);
        foreach ($dependencies as $dependency) {
            require_once self::ROOT_DIRECTORY . "/" . self::$config["dependencies"][$dependency];
        }
    }

    // las dos bases de datos
    public static function databases(): array
    {
        // [archivo de descripción de la base de datos]
        return [
            "MySQL" => ["Data/database-mysql.json"],
            "PostgreSQL" => ["Data/database-pgsql.json"],
        ];
    }

    // los datos de la administración tributaria leídos de la base de datos
    #[DataProvider("databases")]
    public function testTaxAdminData(string $databaseFilename): void
    {
        $dao = new DaoTaxWithTaxAdminDataInDatabase(self::ROOT_DIRECTORY . "/$databaseFilename");
        $taxAdminData = $dao->getTaxAdminData();
        // constantes de cálculo
        $this->assertSame(1551.0, $taxAdminData->halfShareQfCeiling);
        $this->assertSame(21037.0, $taxAdminData->singleIncomeCeilingForReduction);
        $this->assertSame(42074.0, $taxAdminData->coupleIncomeCeilingForReduction);
        $this->assertSame(3797.0, $taxAdminData->halfShareReductionValue);
        $this->assertSame(1196.0, $taxAdminData->singleDiscountCeiling);
        $this->assertSame(1970.0, $taxAdminData->coupleDiscountCeiling);
        $this->assertSame(1595.0, $taxAdminData->singleTaxCeilingForDiscount);
        $this->assertSame(2627.0, $taxAdminData->coupleTaxCeilingForDiscount);
        $this->assertSame(12502.0, $taxAdminData->tenPercentAllowanceMax);
        $this->assertSame(437.0, $taxAdminData->tenPercentAllowanceMin);
        // tramos del impuesto
        $this->assertSame([9964.0, 27519.0, 73779.0, 156244.0, 0.0], $taxAdminData->limits);
        $this->assertSame([0.0, 0.14, 0.30, 0.41, 0.45], $taxAdminData->coeffR);
        $this->assertSame([0.0, 1394.96, 5798.0, 13913.69, 20163.45], $taxAdminData->coeffN);
    }

    // la transferencia del archivo JSON a la base de datos, y luego la relectura de la base de datos
    #[DataProvider("databases")]
    public function testTransfer(string $databaseFilename): void
    {
        // los archivos JSON
        $databaseFilename = self::ROOT_DIRECTORY . "/$databaseFilename";
        $taxAdminDataFilename = self::ROOT_DIRECTORY . "/" . self::$config["taxAdminDataFilename"];
        // transferencia
        (new DaoTransferAdminDataFromJsonFile2Database($databaseFilename, $taxAdminDataFilename))->transferAdminData2Database();
        // relectura de la base de datos por una capa [dao]
        $dao = new DaoTaxWithTaxAdminDataInDatabase($databaseFilename);
        // la base de datos contiene los datos del archivo JSON
        $this->assertEquals(TaxAdminData::fromJsonFile($taxAdminDataFilename), $dao->getTaxAdminData());
    }
}

    Comentarios

    • Líneas 10–12: se importan las clases probadas. La instrucción [use] no carga las clases; solo permite referirse a ellas por sus nombres cortos;
    • línea 22: la configuración de la aplicación se almacena en un atributo estático (de clase);
    • Líneas 26–35: el método estático [setUpBeforeClass] de [TestCase] se ejecuta una sola vez, antes de la primera prueba de la clase. Lee el archivo de configuración y carga los archivos de la aplicación. El curso de PHP 7 realizaba esta tarea en el nivel superior del archivo de prueba, fuera de la clase. Con PHPUnit, este código se ejecuta cuando PHPUnit carga el archivo, en un momento que no controlamos; el método [setUpBeforeClass] está diseñado para este fin;
    • Línea 31: las pruebas de la capa [dao] requieren las dependencias del cálculo del impuesto (para la clase [DaoTaxWithTaxAdminDataInDatabase]) y de la transferencia (para la clase [DaoTransferAdminDataFromJsonFile2Database]). Las dos listas se combinan y luego la función [array_unique] elimina los duplicados;
    • líneas 38–45: la fuente de datos: los archivos de descripción de las dos bases de datos;
    • líneas 48–49: la prueba [testTaxAdminData] de la versión 5 se ejecuta una vez para cada una de las dos bases de datos;
    • líneas 71–83: lo mismo se aplica a la prueba de transferencia de datos del archivo JSON a la base de datos.
