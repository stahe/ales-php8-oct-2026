    8. Ejercicio práctico – Versión 3

    Retomaremos el ejercicio que vimos anteriormente (versiones 1 y 2) y lo resolveremos con código PHP que emplea clases. Pondremos en práctica lo aprendido en los tres capítulos anteriores:

    • una clase [readonly] (inmutable) para representar los datos de la administración tributaria;
    • una interfaz, una clase abstracta que la implementa parcialmente y una clase derivada que la completa;
    • un único tipo de excepción, [TaxException], para informar todos los errores de la aplicación;
    • el atributo [#[\Override]] en todos los métodos que implementan un método de una interfaz o sobrescriben un método del padre.

    Comentarios

    • Línea 6: la clase [TaxException] está en el espacio de nombres [Application]. Todas las clases e interfaces de la aplicación de cálculo del impuesto estarán en este espacio de nombres;
    • línea 9: la clase [TaxException] extiende la clase predefinida de PHP [RuntimeException]. Como vimos en el capítulo sobre excepciones, una excepción se define principalmente por su tipo: es el tipo el que permite capturarla con una cláusula [catch (TaxException $ex)];
    • Líneas 11–12: el curso de PHP 7 definía un constructor [__construct(string $message, int $code = 0)] que simplemente llamaba al constructor de la clase padre. Es innecesario: la clase hereda el constructor de [RuntimeException], que acepta un mensaje, un código de error y una posible excepción anterior. Usaremos este último parámetro para encapsular una excepción de bajo nivel (una [JsonException], por ejemplo) dentro de una [TaxException].

    <?php

declare(strict_types=1);

// espacio de nombres
namespace Application;

// los datos de la administración tributaria: un objeto inmutable
final readonly class TaxAdminData
{
    // los nombres de los arreglos y constantes esperados en los datos
    private const array ARRAYS = ["limits", "coeffR", "coeffN"];
    private const array CONSTANTS = [
        "halfShareQfCeiling",
        "singleIncomeCeilingForReduction",
        "coupleIncomeCeilingForReduction",
        "halfShareReductionValue",
        "singleDiscountCeiling",
        "coupleDiscountCeiling",
        "coupleTaxCeilingForDiscount",
        "singleTaxCeilingForDiscount",
        "tenPercentAllowanceMax",
        "tenPercentAllowanceMin",
    ];

    // constructor privado: hay que pasar por los métodos [from...]
    private function __construct(
        // tramos del impuesto
        public array $limits,
        public array $coeffR,
        public array $coeffN,
        // constantes de cálculo del impuesto
        public float $halfShareQfCeiling,
        public float $singleIncomeCeilingForReduction,
        public float $coupleIncomeCeilingForReduction,
        public float $halfShareReductionValue,
        public float $singleDiscountCeiling,
        public float $coupleDiscountCeiling,
        public float $coupleTaxCeilingForDiscount,
        public float $singleTaxCeilingForDiscount,
        public float $tenPercentAllowanceMax,
        public float $tenPercentAllowanceMin,
    ) {
    }

    // construcción a partir de un archivo JSON
    public static function fromJsonFile(string $taxAdminDataFilename): self
    {
        // recuperamos el contenido del archivo de datos de impuestos
        $fileContents = is_readable($taxAdminDataFilename) ? file_get_contents($taxAdminDataFilename) : false;
        // ¿error?
        if ($fileContents === false) {
            throw new TaxException("The data file [$taxAdminDataFilename] does not exist", 1);
        }
        // decodificamos el JSON en un arreglo asociativo
        try {
            $data = json_decode($fileContents, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new TaxException("The JSON data file [$taxAdminDataFilename] could not be processed correctly", 2, $ex);
        }
        // el JSON debe ser un objeto {...}
        if (!is_array($data)) {
            throw new TaxException("The JSON data file [$taxAdminDataFilename] does not contain a JSON object", 3);
        }
        // construcción del objeto a partir del arreglo asociativo
        return self::fromArray($data);
    }

    // construcción a partir de un arreglo asociativo [name => value]
    public static function fromArray(array $data): self
    {
        // las claves presentes deben ser exactamente las esperadas
        $expected = [...self::ARRAYS, ...self::CONSTANTS];
        $missing = array_first(array_diff($expected, array_keys($data)));
        if ($missing !== null) {
            throw new TaxException("The attribute [$missing] of [TaxAdminData] has not been initialized", 4);
        }
        $unknown = array_first(array_diff(array_keys($data), $expected));
        if ($unknown !== null) {
            throw new TaxException("The attribute [$unknown] does not exist in [TaxAdminData]", 5);
        }
        // verificamos y convertimos cada valor
        $values = [];
        foreach (self::ARRAYS as $key) {
            // un arreglo no vacío de reales >= 0
            if (!is_array($data[$key]) || !array_is_list($data[$key]) || count($data[$key]) === 0) {
                throw new TaxException("The value of attribute [$key] is invalid", 6);
            }
            $values[$key] = array_map(fn(mixed $value): float => self::check($key, $value), $data[$key]);
        }
        // los tres arreglos deben tener el mismo tamaño
        $size = count($values["limits"]);
        if (count($values["coeffR"]) !== $size || count($values["coeffN"]) !== $size) {
            throw new TaxException("The arrays [limits, coeffR, coeffN] do not have the same size", 7);
        }
        foreach (self::CONSTANTS as $key) {
            // un real >= 0
            $values[$key] = self::check($key, $data[$key]);
        }
        // construcción del objeto: las claves del arreglo se convierten en argumentos con nombre
        return new self(...$values);
    }

    // verifica que un valor sea un número real positivo o cero y lo devuelve como [float]
    private static function check(string $key, mixed $value): float
    {
        // aceptamos 1551, 1551.78, "1551" pero no "xx", true, null, -3...
        if ((is_int($value) || is_float($value) || (is_string($value) && is_numeric($value)))
            && (float) $value >= 0) {
            return (float) $value;
        }
        throw new TaxException("The value of attribute [$key] is invalid", 6);
    }

    // cadena JSON del objeto
    public function __toString(): string
    {
        return json_encode(get_object_vars($this), JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
    }
}

    Comentarios

    • Línea 9: la clase es [readonly]: todos sus atributos son de solo lectura. Una vez creado, un objeto [TaxAdminData] ya no se puede modificar: puede compartirse sin riesgo entre todas las partes de la aplicación. También es [final]: no se puede derivar;
    • líneas 12–24: dos constantes de clase privadas enumeran los nombres de los atributos esperados en los datos. A partir de PHP 8.3, una constante de clase puede tener tipo (aquí, [array]);
    • líneas 27–43: el constructor utiliza la promoción de parámetros: cada parámetro se convierte en un atributo público con el mismo nombre y tipo. Los atributos tienen los mismos nombres que las claves del archivo JSON. Este es un punto importante que simplifica mucho la escritura del código, como veremos. Los tramos del impuesto son arreglos ([array]) y las constantes de cálculo son números reales ([float]). En PHP 7, los atributos no podían tener tipo (como se señaló en el curso de PHP 7); pueden tenerlo a partir de PHP 7.4;
    • línea 27: el constructor es private; [new TaxAdminData(...)] no puede escribirse fuera de la clase. Un objeto [TaxAdminData] solo puede obtenerse mediante los métodos estáticos [fromJsonFile] y [fromArray], que verifican la validez de los datos. Esto garantiza que todo objeto [TaxAdminData] contenga datos válidos. En PHP, una clase solo puede tener un constructor. Los métodos estáticos que construyen un objeto, a veces llamados “constructores con nombre”, permiten varias formas de construir un objeto. El curso de PHP 7 usaba métodos de instancia [setFromJsonFile] llamados sobre un objeto vacío: [(new TaxAdminData())->setFromJsonFile(...)]. Esto es imposible con un objeto inmutable;
    • líneas 47–67: el método [fromJsonFile] construye un objeto [TaxAdminData] a partir del archivo JSON cuyo nombre se le pasa. Su tipo de retorno, [self], se refiere a la propia clase;
    • líneas 50–53: se lee el contenido del archivo. Si no es posible, se lanza una excepción [TaxException]. Esta excepción se propagará hasta el script principal;
    • líneas 56–60: se decodifica el contenido del archivo, que es JSON. Con la opción [JSON_THROW_ON_ERROR] (PHP 7.3), la función [json_decode] lanza una excepción [JsonException] cuando el JSON no es válido, en lugar de devolver silenciosamente [null]. Observe el argumento con nombre [flags:], que evita tener que asignar un valor al tercer parámetro [depth] de [json_decode]. La excepción [JsonException] se encapsula dentro de una [TaxException]: el código que llama solo tiene que manejar un tipo de excepción, pero puede determinar la causa original mediante [$ex->getPrevious()];
    • líneas 62–64: un archivo que contenga, por ejemplo, solo el número 12 es un JSON válido; hay que verificar que efectivamente se haya obtenido un arreglo;
    • línea 66: el resto del trabajo se delega en el método [fromArray]. Este método es público: podrá usarse en una versión futura en la que los datos de la administración tributaria provengan de una base de datos;
    • líneas 73–81: se verifica que las claves del arreglo [$data] sean exactamente los nombres esperados. [[...self::ARRAYS, ...self::CONSTANTS]] crea un arreglo con los elementos de ambos arreglos. La función [array_diff] devuelve los elementos del primer arreglo que no están en el segundo, y la función [array_first] (PHP 8.5) devuelve el primer elemento de un arreglo o [null] si el arreglo está vacío. Así se detecta una clave faltante seguida de una clave desconocida. Es el error más frecuente: un error tipográfico en el nombre de un atributo en el archivo [taxadmindata.json]. En el curso de PHP 7, el bucle [$this->$key = $value] creaba silenciosamente un atributo dinámico con el nombre incorrecto. Desde PHP 8.2, la creación de atributos dinámicos está obsoleta y está prohibida dentro de una clase [readonly];
    • líneas 84–90: cada uno de los tres arreglos debe ser una lista no vacía (función [array_is_list], PHP 8.1) cuyos elementos sean todos números reales positivos o cero. La función [array_map] aplica el método [check] a cada elemento;
    • líneas 92–95: los tres arreglos de tramos del impuesto deben tener el mismo tamaño;
    • líneas 96–99: cada una de las constantes de cálculo debe ser un número real positivo o cero;
    • línea 101: el arreglo [$values] usa como claves los nombres de los parámetros del constructor. El operador [...], aplicado a un arreglo con claves de tipo cadena, convierte cada elemento en un argumento con nombre (PHP 8.1): esta línea equivale a [new self(limits: $values["limits"], coeffR: $values["coeffR"], ...)]. Aquí es donde elegir nombres idénticos para las claves JSON y los atributos de la clase simplifica el código;
    • líneas 105–113: el método [check] verifica si un valor [$value] de tipo desconocido ([mixed]) es un número positivo o cero. Según el contenido del archivo JSON, el valor leído puede ser un entero (1551), un número de punto flotante (1551.78), una cadena convertible en número ("1551"), una cadena no convertible ("xx"), un booleano... La función [is_numeric] devuelve [true] para una cadena que representa un número. El curso de PHP 7 realizaba esta verificación con una expresión regular y devolvía un objeto [stdClass] que indicaba si había ocurrido un error. Aquí, un error provoca una excepción y el método simplemente devuelve el número en forma de [float];
    • línea 116: el método [__toString] devuelve la cadena JSON que contiene los atributos del objeto. La función [get_object_vars] devuelve un arreglo asociativo [attribute name => value].

    8.3.1. ¿Por qué ya no hay getters ni setters?

    El curso de PHP 7 declaraba los atributos como privados y escribía un getter y un setter para cada uno (26 métodos), generados automáticamente por el IDE NetBeans. Los setters eran “fluidos”: devolvían el objeto [$this], lo que permitía llamadas encadenadas como [$data->setLimits($limits)->setCoeffR($coeffR)].

    Con PHP 8, este código ya no es necesario:

    • los getters servían para leer atributos privados. Los atributos [readonly] pueden hacerse públicos sin riesgo, puesto que no se pueden modificar: escribimos [$taxAdminData->halfShareQfCeiling] en lugar de [$taxAdminData->getHalfShareQfCeiling()];
    • los setters servían para inicializar el objeto y permitían validar los valores. Un objeto inmutable se inicializa de una vez por todas mediante su constructor, y la validación la realizan los métodos [fromJsonFile] y [fromArray];
    • los atributos tipados garantizan el tipo de los valores. El curso de PHP 7 señalaba que la instrucción [$this->halfShareQfCeiling = 'abcd'] era posible: con atributos [float] y [declare(strict_types=1)], provoca un error [TypeError].

    #[\Override]
    public function calculateTax(string $married, int $children, int $salary): array
    {
        // $married: yes, no
        // $children: número de hijos
        // $salary: salario anual
        // $this->taxAdminData: datos de la administración tributaria
        //
        // recuperamos los datos de la administración tributaria si aún no se ha hecho
        $this->taxAdminData ??= $this->getTaxAdminData();
        // cálculo del impuesto con hijos
        $result1 = $this->calculateTax2($married, $children, $salary);
        $tax1 = $result1["tax"];
        // cálculo del impuesto sin hijos
        if ($children !== 0) {
            $result2 = $this->calculateTax2($married, 0, $salary);
            $tax2 = $result2["tax"];
            // aplicación del tope del cociente familiar
            $halfShareCeiling = $this->taxAdminData->halfShareQfCeiling;
            if ($children < 3) {
                // halfShareQfCeiling euros por los 2 primeros hijos
                $tax2 = $tax2 - $children * $halfShareCeiling;
            } else {
                // halfShareQfCeiling euros por los 2 primeros hijos, el doble por los siguientes
                $tax2 = $tax2 - 2 * $halfShareCeiling - ($children - 2) * 2 * $halfShareCeiling;
            }
        } else {
            $tax2 = $tax1;
            $result2 = $result1;
        }
        // tomamos el impuesto más alto con la tasa y el recargo correspondientes
        if ($tax1 > $tax2) {
            $tax = $tax1;
            $rate = $result1["rate"];
            $surcharge = $result1["surcharge"];
        } else {
            $surcharge = $tax2 - $tax1 + $result2["surcharge"];
            $tax = $tax2;
            $rate = $result2["rate"];
        }
        // cálculo de un posible descuento
        $discount = $this->getDiscount($married, $salary, $tax);
        $tax -= $discount;
        // cálculo de una posible reducción de impuesto
        $reduction = $this->getReduction($married, $salary, $children, $tax);
        $tax -= $reduction;
        // resultado
        return [
            "tax" => (int) floor($tax),
            "surcharge" => (int) $surcharge,
            "discount" => (int) $discount,
            "reduction" => (int) $reduction,
            "rate" => $rate,
        ];
    }

    private function calculateTax2(string $married, int $children, float $salary): array
    {
        // número de partes
        $nbShares = match ($married) {
            "yes" => $children / 2 + 2,
            "no" => $children / 2 + 1,
        };
        // 1 parte por hijo a partir del tercero
        if ($children >= 3) {
            // media parte más por cada hijo a partir del tercero
            $nbShares += 0.5 * ($children - 2);
        }
        // ingreso gravable
        $taxableIncome = $this->getTaxableIncome($salary);
        // recargo
        $surcharge = floor($taxableIncome - 0.9 * $salary);
        // por problemas de redondeo
        if ($surcharge < 0) {
            $surcharge = 0;
        }
        // cociente familiar
        $quotient = $taxableIncome / $nbShares;
        // los tramos del impuesto (copias de los arreglos del objeto)
        $limits = $this->taxAdminData->limits;
        $coeffR = $this->taxAdminData->coeffR;
        $coeffN = $this->taxAdminData->coeffN;
        // se coloca al final del arreglo de límites para detener el bucle siguiente
        $limits[count($limits) - 1] = $quotient;
        // cálculo del impuesto
        $i = 0;
        while ($quotient > $limits[$i]) {
            $i++;
        }
        // ahora podemos calcular el impuesto
        $tax = floor($taxableIncome * $coeffR[$i] - $nbShares * $coeffN[$i]);
        // resultado
        return ["tax" => $tax, "surcharge" => $surcharge, "rate" => $coeffR[$i]];
    }

    // taxableIncome=annualSalary-allowance
    // la deducción tiene un mínimo y un máximo
    private function getTaxableIncome(float $salary): float
    {
        // deducción del 10% del salario, acotada por un mínimo y un máximo
        $allowance = 0.1 * $salary;
        $allowance = min($allowance, $this->taxAdminData->tenPercentAllowanceMax);
        $allowance = max($allowance, $this->taxAdminData->tenPercentAllowanceMin);
        // ingreso gravable
        $taxableIncome = $salary - $allowance;
        // resultado
        return floor($taxableIncome);
    }

    // calcula un posible descuento
    private function getDiscount(string $married, float $salary, float $taxes): float
    {
        // al inicio, un descuento nulo
        $discount = 0;
        // monto máximo de impuesto para obtener el descuento
        $taxCeilingForDiscount = $married === "yes"
            ? $this->taxAdminData->coupleTaxCeilingForDiscount
            : $this->taxAdminData->singleTaxCeilingForDiscount;
        if ($taxes < $taxCeilingForDiscount) {
            // monto máximo del descuento
            $discountCeiling = $married === "yes"
                ? $this->taxAdminData->coupleDiscountCeiling
                : $this->taxAdminData->singleDiscountCeiling;
            // descuento teórico
            $discount = $discountCeiling - 0.75 * $taxes;
            // el descuento no puede superar el monto del impuesto
            if ($discount > $taxes) {
                $discount = $taxes;
            }
            // ningún descuento < 0
            if ($discount < 0) {
                $discount = 0;
            }
        }
        // resultado
        return ceil($discount);
    }

    // calcula una posible reducción
    private function getReduction(string $married, float $salary, int $children, float $taxes): float
    {
        // el tope de ingresos para tener derecho a la reducción del 20%
        $incomeCeilingForReduction = $married === "yes"
            ? $this->taxAdminData->coupleIncomeCeilingForReduction
            : $this->taxAdminData->singleIncomeCeilingForReduction;
        $incomeCeilingForReduction += $children * $this->taxAdminData->halfShareReductionValue;
        if ($children > 2) {
            $incomeCeilingForReduction += ($children - 2) * $this->taxAdminData->halfShareReductionValue;
        }
        // ingreso gravable
        $taxableIncome = $this->getTaxableIncome($salary);
        // reducción
        $reduction = 0;
        if ($taxableIncome < $incomeCeilingForReduction) {
            // reducción del 20%
            $reduction = 0.2 * $taxes;
        }
        // resultado
        return ceil($reduction);
    }

        // cálculo del impuesto en modo por lotes
    // --------------------------------------------------------------------------
    #[\Override]
    public function executeBatchTaxes(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void
    {
        // los tres archivos aún no están abiertos
        $errors = $results = $data = false;
        // pueden ocurrir bastantes errores en cuanto se manejan archivos
        try {
            // apertura del archivo de errores
            $errors = fopen($errorsFileName, "w");
            if ($errors === false) {
                throw new TaxException("Unable to create the errors file [$errorsFileName]", 10);
            }
            // apertura del archivo de resultados
            $results = fopen($resultsFileName, "w");
            if ($results === false) {
                throw new TaxException("Unable to create the results file [$resultsFileName]", 11);
            }
            // apertura del archivo de datos de los contribuyentes
            $data = is_readable($taxPayersFileName) ? fopen($taxPayersFileName, "r") : false;
            if ($data === false) {
                throw new TaxException("Unable to open the taxpayers' declarations [$taxPayersFileName] for reading", 12);
            }
            // procesamos la línea actual del archivo de datos de los contribuyentes
            // que tiene la forma estado civil, número de hijos, salario anual
            $num = 0;         // n.º de la línea actual
            $nbErrors = 0;    // número de errores encontrados
            while (($line = fgets($data, 100)) !== false) {
                // una línea más
                $num++;
                // eliminamos la posible marca de fin de línea
                $line = Utilities::cutNewLineChar($line);
                // ignoramos las líneas vacías
                if (trim($line) === "") {
                    continue;
                }
                // la línea debe tener 3 campos married,children,salary
                $fields = array_map(trim(...), explode(",", $line));
                $error = count($fields) !== 3;
                if (!$error) {
                    [$married, $children, $salary] = $fields;
                    // el estado civil debe ser yes o no
                    $married = strtolower($married);
                    // el número de hijos y el salario deben ser enteros positivos o cero
                    $error = !in_array($married, ["yes", "no"], true)
                        || !preg_match('/^\d+$/', $children)
                        || !preg_match('/^\d+$/', $salary);
                }
                // ¿error?
                if ($error) {
                    fputs($errors, "line [$num] of the file [$taxPayersFileName] is incorrect\n");
                    $nbErrors++;
                    continue;
                }
                // calculamos el impuesto
                $result = $this->calculateTax($married, (int) $children, (int) $salary);
                // escribimos el resultado en el archivo de resultados
                $result = ["married" => $married, "children" => (int) $children, "salary" => (int) $salary] + $result;
                fputs($results, json_encode($result, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR) . "\n");
            }
            // ¿errores?
            if ($nbErrors > 0) {
                throw new TaxException("There were $nbErrors incorrect line(s): see the file [$errorsFileName]", 15);
            }
        } finally {
            // cerramos los archivos que se abrieron
            foreach ([$data, $results, $errors] as $file) {
                if ($file !== false) {
                    fclose($file);
                }
            }
        }
    }

    Comentarios del código

    • Línea 185: el método recibe tres parámetros:
      • [$taxPayersFileName]: el nombre del archivo de texto que contiene los datos de los contribuyentes. Cada línea de texto contiene los datos de un contribuyente con el siguiente formato: estado civil (yes/no), número de hijos, salario anual; por ejemplo, [yes,2,55555];
      • [$resultsFileName]: el nombre del archivo de texto que contendrá los resultados. Cada línea de texto será la cadena JSON que representa los resultados de un contribuyente, por ejemplo, [{"married":"yes","children":2,"salary":50000,"tax":1384,"surcharge":0,"discount":384,"reduction":347,"rate":0.14}];
      • [$errorsFileName]: el nombre del archivo de texto que contiene los errores, por ejemplo, [line [5] of the file [taxpayersdata.txt] is incorrect];
    • línea 188: las variables de los tres archivos se inicializan en [false] (archivo no abierto). Esto permitirá determinar, en la cláusula [finally], qué archivos se han abierto;
    • línea 190: como varias operaciones pueden lanzar una excepción, una estructura [try / finally] encierra todo el código del método;
    • líneas 192–204: se abren los tres archivos. Se lanza una excepción en cuanto falla una operación de apertura, con un código de error distinto para cada caso;
    • línea 210: las líneas del archivo [$data] se leen una por una en bloques de hasta 100 caracteres (todas las líneas tienen menos de 100 caracteres);
    • línea 214: se utiliza el método estático [Utilities::cutNewLineChar] para eliminar los posibles caracteres de fin de línea;
    • líneas 216–218: se ignoran las líneas vacías (por ejemplo, al final del archivo);
    • línea 220: la línea se divide en la coma y se eliminan los espacios que rodean a cada campo. [trim(...)] es la sintaxis de los “first-class callables” (PHP 8.1): hace referencia a la propia función [trim], sin llamarla;
    • línea 221: la línea debe tener exactamente tres campos. El curso de PHP 7 escribía directamente [list($married, $children, $salary) = explode(",", $line)]: con una línea que tenga solo dos campos, PHP 8 emite una advertencia “Undefined array key 2”;
    • líneas 227–229: se verifica la validez de los tres elementos: el estado civil debe ser “yes” o “no”, y el número de hijos y el salario deben ser enteros positivos o cero (una secuencia de dígitos, expresión regular [/^\d+$/]). El tercer parámetro [true] de [in_array] exige una comparación estricta [===];
    • líneas 232–236: no se lanza ninguna excepción si la línea no es válida; en su lugar, se escribe un mensaje de error en el archivo de texto [$errors], y el programa pasa a la línea siguiente;
    • línea 238: si la línea leída es válida, se calcula el impuesto. El resultado se devuelve como un arreglo asociativo [tax, surcharge, discount, reduction, rate];
    • línea 240: las claves [married, children, salary] se agregan al principio del resultado;
    • línea 241: el resultado se escribe en el archivo de texto [$results] en forma de cadena JSON. La opción [JSON_THROW_ON_ERROR] hace que la función [json_encode] lance una excepción [JsonException] en lugar de devolver [false] si falla la codificación;
    • líneas 244–246: al terminar de procesar el archivo [$data], se verifica el número de líneas erróneas encontradas. Si hay al menos una, se lanza una excepción;
    • líneas 247–254: sea cual sea la manera en que termine la ejecución del método (normalmente o mediante una excepción), se ejecuta la cláusula [finally] : se cierran los archivos que se hayan abierto. El curso de PHP 7 usaba una estructura [try / catch / finally] cuya cláusula [catch] simplemente relanzaba la excepción. Esto es innecesario: una estructura [try / finally] sin [catch] permite que la excepción se propague después de que se haya ejecutado la cláusula [finally]. Además, el curso de PHP 7 cerraba los tres archivos sin verificar que se hubieran abierto: en PHP 8, [fclose(false)] provoca un error [TypeError].

    <?php

declare(strict_types=1);

// espacio de nombres
namespace Application;

// una clase que toma los datos de la administración tributaria de un archivo JSON
class TaxWithTaxAdminDataInJsonFile extends AbstractBaseTax
{
    // los datos de la administración tributaria
    private readonly TaxAdminData $taxAdminData;

    // el constructor
    public function __construct(string $jsonFileName)
    {
        // inicializamos $this->taxAdminData a partir del archivo JSON
        // puede lanzar una excepción TaxException
        $this->taxAdminData = TaxAdminData::fromJsonFile($jsonFileName);
    }

    // devuelve los datos usados para calcular el impuesto
    #[\Override]
    public function getTaxAdminData(): TaxAdminData
    {
        return $this->taxAdminData;
    }
}

    Comentarios

    • Línea 9: la clase [TaxWithTaxAdminDataInJsonFile] extiende la clase abstracta [AbstractBaseTax]. Debe definir el método [getTaxAdminData], que su clase padre no ha definido;
    • Línea 12: el atributo [$taxAdminData] contendrá los datos de la administración tributaria. Es de solo lectura: lo inicializa el constructor de una vez por todas. Observe que la clase padre también tiene un atributo privado [$taxAdminData]: los dos atributos son distintos, ya que un atributo privado solo es visible dentro de la clase que lo declara;
    • líneas 15–20: el constructor recibe como único parámetro el nombre del archivo JSON que contiene los datos del impuesto;
    • línea 19: se crea un objeto de tipo [TaxAdminData] a partir del archivo JSON. Esta operación puede lanzar una excepción de tipo [TaxException]. Esta excepción se propagará hasta el script principal [main.php];
    • Líneas 23–27: se proporciona un cuerpo para el método [getTaxAdminData], que la clase padre no había definido. Aquí basta con asegurarse de que el atributo [$this->taxAdminData] sea inicializado por el constructor.

    8.10. Conclusión

    La versión 3 tiene la misma funcionalidad que la versión 2, pero está mejor preparada para manejar errores: datos tributarios incompletos o incorrectos, líneas erróneas en el archivo de contribuyentes o archivos faltantes. Cada error se señala mediante una excepción [TaxException] que incluye un mensaje y un código específico.

    Sin embargo, la clase [AbstractBaseTax] combina dos tipos de código: el cálculo del impuesto, por un lado, y la lectura y escritura de archivos, por otro. En los capítulos siguientes veremos cómo separar estas dos responsabilidades en capas distintas.
