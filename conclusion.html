    25. Conclusión

    Este documento presentó el lenguaje PHP 8 mediante numerosos scripts y un hilo conductor común (el cálculo del impuesto sobre la renta), desarrollado en 13 versiones:

    • Las versiones 1 y 2 implementan el cálculo con funciones y archivos de texto o JSON;
    • La versión 3 lo escribe con clases y la versión 4 lo organiza en capas [dao] / [business] / [console], probadas con [PHPUnit];
    • las versiones 5 a 7 obtienen los datos del impuesto de una base de datos ([MySQL]), luego de [PostgreSQL], y después de una u otra según un simple archivo de configuración;
    • las versiones 8 a 11 convierten el cálculo en un servicio web, con un cliente de consola: autenticación, sesiones, registro, envío de correos electrónicos al administrador, caché [Redis], respuestas JSON y luego XML;
    • La versión 12 es una aplicación web (MVC) que puede responder en JSON, XML o HTML, con su cliente de consola;
    • la versión 13 protege los archivos de la aplicación haciendo visible desde la web únicamente la carpeta [public].

    En el camino, hemos visto la mayor parte de lo que PHP 8 ofrece en comparación con PHP 7: el tipado estricto y los tipos de los parámetros, los resultados y los atributos; las clases y los atributos de solo lectura, la promoción de parámetros del constructor, las enumeraciones, los property hooks y la visibilidad asimétrica de PHP 8.4; la expresión [match], el operador null-safe, los argumentos con nombre y el operador pipe de PHP 8.5; los errores que se convirtieron en excepciones; la nueva API [PDO] y [DOM]. También hemos visto, cada vez, lo que PHP ha eliminado: ninguno de los scripts de este documento muestra un mensaje [Deprecated] con PHP 8.5.

    La arquitectura del servidor de la versión 12 (un controlador principal, controladores secundarios, las capas [business] y [dao], respuestas JSON, XML o HTML) es la de los frameworks web modernos, como [Symfony] o [Laravel], de los cuales, de hecho, hemos utilizado algunos componentes ([HttpFoundation], [HttpClient], [Mailer]). Quienes hayan completado este curso ya cuentan con la base para abordar uno de estos frameworks.

    El servicio web JSON de la versión 12 también puede tener otros clientes además del cliente de consola escrito en PHP: un cliente JavaScript que se ejecute en un navegador, una aplicación móvil, etc. Esta es la arquitectura cliente/servidor presentada en la introducción de este documento.
